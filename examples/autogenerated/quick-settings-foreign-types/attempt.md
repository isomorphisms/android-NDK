## Type-system sketch

### Values and domains

TileService and Tile are opaque framework references. NullableTile is a distinct
opaque result domain which may contain Android null. NullableReference a is a
second, indexed spelling whose index names the referred-to object domain.

### Types and signatures

Each opaque domain uses the existing `[external]` data declaration marker.
`read_tile : TileService → IO NullableTile` and
`read_indexed_tile : TileService → IO (NullableReference Tile)` describe foreign
effects. The index is a static distinction, not an assumed runtime box.

### Actions and effects

Foreign primitive declarations return PrimIO; their wrappers return IO.
Neither action is evaluated on this host.

### Laws, invariants, and errors

The source must not claim that a nullable reference is nonnull. No conversion,
null test, or proof is invented. Source acceptance does not establish how DEX
represents the reference or whether its backend accepts these foreign types.

### Runtime and backend boundary

The eventual call refers to Android TileService.getQsTile via a DEX foreign
string. This probe runs only the existing Idriç frontend `--check` and supplies
no alternative backend or runtime.
