# Program attempt: six-word DEX invocation

Status: `PARTIAL`

## Purpose

Exercise the direct DEX call boundary needed by Quick Settings without assigning
a tile any product behavior. The real public `String.regionMatches` overload
has five declared parameters and a receiver, exceeding format 35c's five words.

## Intended behavior

Accept two strings and explicit `Int32` offsets/length. Call the public platform
method once and return its Boolean result as the DEX `Z` ABI value represented
by the binding's explicit `Int32`. Case-sensitive and case-insensitive cases,
unequal offsets, and a false match distinguish argument order.

## Type-system sketch

### Values and domains

Text values are real `java.lang.String` references. Offsets and lengths use
explicit `Int32`; the framework Boolean argument/result retains descriptor `Z`.
Compiler register positions and DEX code units are target metadata.

### Types and signatures

The foreign operation is `Text -> Int32 -> Int32 -> Text -> Int32 -> Int32 ->
Int32`, with descriptor `(ZILjava/lang/String;II)Z` and the first Text as receiver.
The generated export takes the same six values and returns `Int32`.

### Actions and effects

This String comparison is a pure call. Separate Parcel source fixtures cover
PrimIO sequencing and void actions; this probe isolates the six-word call ABI.

### Laws, invariants, and errors

Receiver precedes declared arguments. Every reference occupies one DEX word,
an explicit long occupies a consecutive pair, and 3rc arguments occupy a
contiguous register interval. Staging must use fresh registers and preserve
incoming parameters, object/wide move families, and result adjacency.
Invalid widths, out-of-frame registers, and unencodable frames are rejected.

### Runtime and backend boundary

Checked Idriç source must produce its typed plan and DEX directly. Host encoder
unit tests cover boundary bytes and safe placement; disassembly can check the
artifact independently. ART execution is a separate result and requires an
available runtime. No Java source, JNI, Gradle, RefC, or smali candidate is used.

## Result or failure

The preserved emitter's first concrete limitation was 35c-only invocation.
The extension now chooses 35c/3rc, checks word counts, and safely stages calls
whose arguments are discontiguous or whose result requires a low register.

Frontend checking passed for both String exports. Host execution printed
`PASS: DEX invocation placement and word counts`; the existing encoder
self-test also passed after the typed method API change. After removing
unrelated historical Binder/catch support, fresh source checks passed for
IR, Invoke, Placement, Encode, Smali, and the revised host regression source.
The combined host verifier reruns the final executable against that narrowed
tree. ART execution remains a separate result.

Initial environment failures were a full filesystem while writing a TTC and
an unavailable generic `scheme` command; the compiler reported exit zero for
those failures. Fresh output files and diagnostic inspection were required.
Space was recovered by the root task, and the exact existing Scheme executable
was selected. These were not Idriç language successes or backend fallbacks.
