## Purpose and type boundary

The existing IB `NativeSourceProjection.source_title : Text → Text` must call
its unchanged recovery/token/information helpers, including their changing
list and record accumulators. It must remain a callable pure export rather
than being rewritten as a command solely to select the managed runtime.

The source boundary is one checked explicit Text parameter and a pure Text
result. The external DEX descriptor is `(Ljava/lang/String;)Ljava/lang/String;`.
The existing managed helper ABI remains internal: `(Object) → Object`.
A generated wrapper calls that checked body and checks its result as String.
No source list, record, closure, or world token becomes a foreign descriptor.
ART owns the transient managed objects; the wrapper adds no argument globals,
JNI mapping, implicit native-library loader, synthetic World or main method.

Selection uses both the checked source ABI and actual reachable non-scalar
constructor allocation. Merely calling string unpack/pack does not select it;
the existing view-only Unpack path and scalar exports remain in place.
Constructors in either branch and recursive reachable helpers must count.
The complete selected graph still passes the existing managed lowering and
encoder validation. Unsupported source signatures, ANF/source arity mismatch,
IO foreign services and generated-name collisions must refuse before DEX.
