# Checked source actions retained by Runnable

`dex:capture-runnable` is a narrow factory for a real platform Runnable:

```idric
data RunnableReference : Type where [external]

%foreign "dex:capture-runnable"
capture_runnable : IO () → PrimIO RunnableReference
```

The foreign metadata must contain exactly `PrimIO.IO Unit`, then the trailing
World token, with an IORes result in one concrete checked external domain. The
external-domain pass associates that result with `Ljava/lang/Runnable;` and
rejects an ordinary ADT or a conflicting descriptor. Pure factories, arbitrary
functions, other IO result types, extra arguments and scalar results refuse.
The private IO argument receives no public Object descriptor. Public exports
continue to admit only the existing scalar and validated external domains.

The pinned frontend removes the IO newtype around its private World closure.
The factory retains that checked closure in a private final per-instance field
of `Idric.Generated$CapturedRunnable`. It does not execute the action. A later
platform `run()` loads the field and calls the existing checked `__idricApply`
dispatcher with the erased World token. That dispatcher copies the captured
node before supplying World; repeated dispatch preserves the original closure.
Each callback owns its own reference. There is no global request slot, native
application state or serialization boundary.

The source operation selects the managed export path when reachable. Its
synthetic class uses the same typed IR, register placement, finalized class
plans and shared binary writer as Generated. Instance object accesses validate
their field kind separately from static accesses, and stage high registers
through two disjoint object scratch slots. The main readable evidence remains
`NAME.smali`; the callback class is `NAME.captured-runnable.smali`. Both come
from the finalized plans encoded into the same DEX. The combined plan and
runtime receipt describe both classes. Without this reachable operation, no
callback class is emitted.

The program and qualification are in
`examples/autogenerated/captured-runnable`. They capture an ordinary source
record containing an ADT, Text and a List Text, plus a platform StringBuilder.
The independent observer checks distinct deferred actions, repeated execution,
retention after the factory's local reference is gone and GC pressure, real
Thread and Executor dispatch, Unicode and a source interface call. Compiled
order and Text mutations must fail the observer's behavior assertion.
Their observer main prints that assertion and exits 93; another Throwable exits
94. Only exit 93 with the exact expected assertion qualifies as mutation
rejection. Abnormal process death remains failure with retained diagnostics.

This factory has no event arguments or result. It adds no exception recovery,
cancellation policy, Activity ownership or lifecycle retention policy. Those
remain source/application responsibilities. Generic managed closure support,
emission, ART dispatch, an installed Android Activity and physical-device
acceptance are separate results; the attempt record reports which ran.
