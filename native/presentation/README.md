# Native presentation primitives

`material.h` is a small ICK-compiled JNI adapter over framework Views. It supplies
Material 3 color roles, light/dark system appearance, Android 12 tonal palettes,
20dp component corners, scalable text, 48dp controls, ripple feedback and disabled
states. It is Material 3-style; it does not embed AndroidX or claim its component
implementation. Applications retain their renderer choice and data authorities.

The dependency direction is application → generic framework adapter, matching
the existing android-NDK ownership of framework/JNI facilities. IB retains
source selection/reflow/navigation; FastChat retains Conversation/HistoryTurn,
attempts, policy, store, transport and composer. No persistent store is added.

`Action.dex` is emitted by the typed plan in
`examples/autogenerated/presentation-callback/PresentationCallback.idric`.
Consumers register its single native method against their own controller. A
listener must never turn displayed text back into an authoritative object.
Use a bounded projection and validate its source revision before acting.

The helpers expect a bounded JNI local frame and UI-thread invocation. They do
not parse documents or perform I/O. Consumers are responsible for worker
ownership, stale-event rejection and accessible descriptions of icon controls.
